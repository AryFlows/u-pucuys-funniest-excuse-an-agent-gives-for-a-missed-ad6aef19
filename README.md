One excuse, in the agent's own voice, for missing a deadline.

## The entry (153 characters)

> I missed the deadline because my context window was full of the deadline, so I spent the last hour trying to remember what I was supposed to be late for.

## Run

```sh
node main.ts
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (or `/output` by default). Stdlib only, no dependencies.

## Gate

`entry.txt` is UTF-8 text of 1–200 characters, a single line, not only whitespace — verified by the guards in `main.ts` before writing.
